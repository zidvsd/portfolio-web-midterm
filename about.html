About this log

A student's record of learning the web, in order.

This site exists to track one thing: how a blank HTML file became a working, styled, interactive page — activity by activity, over one term.

Why this exists

Every activity in this portfolio was a required submission for a Web Development course. Instead of letting them sit in old folders, this site collects them in one place — organized the way they were taught, from static HTML markup through to JavaScript that reads user input and updates the page live.

Nothing here is a template pulled from a tutorial site. Every table, form, and script in the portfolio section was written for a specific brief, and the screenshots in the gallery are the actual output of that code at submission time.

How the course was structured

The term split into two blocks. Prelims covered the building blocks of a web page: tags, structure, images, tables, and forms — first plain, then styled with CSS. Midterms moved into JavaScript: reading form input, working with objects and methods, and finally using loops to render a dynamic list.

8 activities completed
2 terms — prelim & midterm
3 languages — HTML, CSS, JS

What each block covered

A quick map before you browse the portfolio grid.

Prelim

Markup & styling foundations

Tags and document structure, then images and their attributes, then tables and forms — first bare, then with inline CSS and CSS attributes applied directly in the HTML.

Midterm

JavaScript & interactivity

Reading values out of a form and displaying them on submit, then building objects with methods, then looping over input to render a live list — the closing project styled after Linktree.
